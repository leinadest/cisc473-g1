# CISC 473 Project

Novel contribution for Zero-DCE and Zero-DCE++ in extreme dark and underwater domains.

## Prerequisites

- conda v25.5.1

## Environment & installation

**Enter project directory**

```sh
cd CISC473Project
```

**Set up conda environments**

```sh
cd ./models/Zero-DCE
conda env create --prefix ./env --file environment.yml
conda activate ./env
```
